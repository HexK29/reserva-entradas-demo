🔒 Compra Segura (con transacción)

¿Cómo funciona?
Cuando dos personas compran al mismo tiempo, la base de datos bloquea la fila del evento. La segunda persona espera hasta que la primera termine. Así nunca se vende el mismo asiento dos veces.
